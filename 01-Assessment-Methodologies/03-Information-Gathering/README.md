# Information Gathering

## Overview

Information gathering is the process of collecting information about a target before performing deeper scanning, enumeration, vulnerability assessment, and exploitation.

This stage helps identify useful information about the target, its infrastructure, domains, subdomains, technologies, services, and other publicly available information that can support the assessment.

## Topics Covered

- Passive Information Gathering
- Active Information Gathering
- Reconnaissance
- Footprinting
- OSINT
- Domain Information

- Subdomain Enumeration
- Email and User Information
- Technology Identification
- Publicly Available Information

## Information Gathering Approach

```text
Target
  ↓
Passive Information Gathering
  ↓
Active Information Gathering
  ↓
Identify Infrastructure
  ↓
Identify Technologies and Services
  ↓
Prepare for Scanning and Enumeration
```

## Purpose

The purpose of this section is to understand how information collected during reconnaissance can be used to build an initial picture of the target and guide the next stages of a penetration test.
