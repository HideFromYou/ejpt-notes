# Security Auditing Fundamentals

## Overview

Security auditing is the systematic process of evaluating an organization's systems, configurations, security controls, policies, and procedures to identify weaknesses, gaps, and areas of risk.

This section covers the fundamental concepts of security auditing, the auditing process, different types of security audits, security policies, standards and frameworks, and Governance, Risk, and Compliance (GRC).

## Purpose

The purpose of this section is to establish a fundamental understanding of security auditing and how it differs from penetration testing.

It provides the foundation for understanding how security assessments are planned, conducted, analyzed, and documented.
