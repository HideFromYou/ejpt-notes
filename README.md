# eJPT Notes

Personal notes and study material for the **eLearnSecurity Junior Penetration Tester (eJPT)** certification.

This repository contains my personal knowledge base covering penetration testing methodologies, host and network auditing, host and network penetration testing, web application penetration testing, practical techniques, tools, and commands.

The notes combine material from my eJPT training with additional personal notes and practical observations collected during my studies.

---

## Repository Structure

### 01 - Assessment Methodologies

Covers the fundamental methodologies used during penetration testing and security assessments, including information gathering, footprinting, scanning, enumeration, and vulnerability assessment.

### 02 - Host and Network Auditing

Covers information gathering and auditing techniques performed against systems and networks, including system information, network information, users, credentials, hashes, and file transfer.

### 03 - Host and Network Penetration Testing

Covers the practical exploitation of hosts and network services, including system and host-based attacks, network-based attacks, exploitation, Metasploit Framework, password attacks, post-exploitation, privilege escalation, and pivoting.

### 04 - Web Application Penetration Testing

Covers web application technologies, web reconnaissance, web server and directory enumeration, vulnerability scanning, web application vulnerabilities, CMS security, WordPress, and web-based brute-force techniques.

### 05 - Cheatsheets

Quick-reference material for commonly used penetration testing tools, commands, services, ports, and techniques.

### 06 - Labs and Practical Notes

Practical exercises, lab notes, methodologies, and lessons learned from hands-on penetration testing practice.
